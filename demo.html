One verification API for the listing flow

Marketplaces submit listings before publication. Sellers receive reasons and evidence requests. Shoppers see a decision report, and reviewers investigate uncertain cases.

Each transaction runs identity, category, and advertising text checks against synthetic fixtures. Declared permit conflicts request review. Evidence upload and reviewer decisions are planned.

Confidence below 0.75 routes a case to human review. Registry outages and unmapped categories produce Unknown. Every decision step contributes to the audit trace.

API as a service

Planned marketplace integration includes authorized registry adapters, scoped marketplace credentials, evidence rechecks, and a risk-ranked reviewer queue. AI extraction is planned for phrases present in the listing, while deterministic rules determine the result.

Illustrative business model from the product brief includes a free seller allowance, a brand subscription, and marketplace pricing per API call. Live registry integration and production persistence require further development.
